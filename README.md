# Financial Data Analyzer
> A Python-based financial analytics project — bridging Finance, Data Analytics, and Data Science.

**Python • Pandas • Matplotlib • Pytest | Financial Analytics • Data Visualization • Business Insights**

#### Video Demo: https://youtu.be/U-0tree0j_o

#### Description:

Financial Data Analyzer is a Python-based financial analysis application designed to evaluate a company's financial performance using monthly revenue and expense data.

The idea for this project was inspired by my professional experience in financial management, financial analysis, and business decision-making. Having worked with financial data in real-world organizational environments, I wanted to build a Python application that reflects some of the practical analytical processes used when reviewing financial performance and supporting management decisions.

The project accepts a CSV file containing monthly financial information and performs a series of financial calculations and analytical checks. It calculates total revenue, total expenses, net profit, profit margin, expense ratio, and revenue growth. In addition, it provides monthly profitability analysis to identify the strongest and weakest months based on net profit.

The application also evaluates financial performance through two additional indicators: a financial health assessment and a financial risk classification. The health score combines profitability and revenue growth into a simple score out of 100. The risk classification evaluates profit margin, revenue growth, and expense ratio to categorize the company's financial risk as Low Risk, Medium Risk, or High Risk.

Data validation is an important part of the application. The program checks whether the input file exists, verifies that the required columns are present, validates numerical financial data, detects missing values, and prevents negative revenue or expense values from being processed.

The project also generates a financial chart using Matplotlib. The chart compares monthly revenue and expenses and provides a visual representation of the company's financial performance throughout the year.

Finally, the program generates management insights based on the calculated financial indicators. These insights summarize revenue growth, profitability, expense control, the strongest and weakest months, and the current financial risk level.

#### Design Choices:

I designed the project as a small financial analytics pipeline rather than a simple calculator. The application follows a sequence of data loading, validation, financial calculation, monthly analysis, risk assessment, visualization, and management insight generation.

The financial logic was separated into individual functions so that each analytical component could be tested independently. This makes the application easier to understand, maintain, test, and extend.

Pandas was selected to simplify CSV data handling, validation, and structured financial analysis. Matplotlib was selected to create a visual comparison between monthly revenue and expenses.

Pytest is used to test the core functionality of the application. The test suite covers financial calculations, revenue growth, monthly profitability, financial health, risk classification, data validation, chart generation, and management insights.

The financial risk and health indicators are intentionally simplified for this educational project. They are designed to demonstrate how financial metrics can be combined into decision-support indicators rather than to replace a professional financial risk model.

The project was designed with practical business and financial analysis in mind. Future versions could be extended with additional financial ratios, Excel support, database integration, interactive dashboards, automated reporting, or integration with financial data sources.

#### How to Run:

Install the required libraries using:

```bash
pip install -r requirements.txt
```

Then run the application:

```bash
python project.py
```

When prompted for the CSV filename, enter:

```text
sample_financial_data.csv
```

To run the automated tests:

```bash
pytest
```

The current test suite contains 13 tests.
